How I work

Four habits that show up in every project, with the moment each one mattered.

Legrand Arteor

Logic before looks

Wireframes settled structure, behaviour and validation states before any visual design. Format comes first because it sets the rules for every step after it.

One Health Assist

Show value before asking

No competitor showed a personal score before payment. We scored what we could measure, labelled it preliminary, and left missing data out instead of counting it as zero.

Legrand Arteor

Prevent errors, don’t explain them

When a module doesn’t fit, the plate offers only sizes that do and places the module for you. People never have to decode an error message.

Oman Vision 2040

Design for the room

Nobody reads in a noisy hall. Static info cards held people for under 10 seconds, so the depth moved into film people can watch while standing in a crowd.

About

From the manual to the last edge case

I like projects that arrive as a dense document: a clinical manual, a product rulebook, a national strategy. My job is to find the structure inside it and turn that into a path a real person can finish.

I have designed for healthcare, building products and government, on phones, web tools and large-format touch displays.
